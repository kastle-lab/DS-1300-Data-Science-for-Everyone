| 6    | Tue      | Feature engineering (2)          | **Encoding (Words to numbers):** Models only read math. Use One-Hot or Label Encoding for categories.<br><br>**Binning (Numbers to groups):** Grouping continuous numbers into buckets (e.g., Low, Medium, High).<br><br>**Scaling (Same scale):** Squeezing all numbers into the same range (e.g., 0 to 1) so large values don't overpower small ones.<br><br>**Aggregation:** Summarizing detailed rows into high-level features (e.g., daily data into monthly totals).<br><br>**Rule of Thumb:** More columns is not always better. Too many features cause overfitting and confuse the model!                                                                                    |                                                                                                                                                                  |

| 7    | Tue      | Predictive modelling (1)         | **What is a model:** A mathematical engine that learns patterns from data to make predictions.<br><br>**Types of Learning:**<br>• Supervised (learning with an answer key)<br>• Unsupervised (finding hidden patterns without labels)<br>• Generative (creating new data from patterns)<br><br>**Supervised Tasks:**<br>• Regression (predicting a continuous number)<br>• Classification (predicting a category or label)<br><br>**Train & Test Split:** Hiding a chunk of data from the model during training so we can test it on unseen data later.<br><br>**Baseline:** The "just guessing" rule (e.g., always guessing the average) to prove our model is actually doing something useful.<br><br>**Model Fit (Intro):**<br>• Overfitting (memorizing the training data, failing in real life)<br>• Underfitting (too simple, failing to learn the patterns at all)                                                                                | **Assignment 2 given**                                                                                                                                           |
